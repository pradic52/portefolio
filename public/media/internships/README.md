Place internship photos and videos in this folder, organized by stage if desired:

- `sote/`
- `mfc-tech/`
- `info-quebec/`

Then add each media item to the matching `media` array in `src/components/Experience.tsx`.
Use `type: "image"` or `type: "video"`, a public URL such as `/media/internships/sote/photo.jpg`, and descriptive `alt` text. The gallery accepts any number of items.
